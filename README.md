Water Tank Overflow Alert System

Project Description

An Arduino-based system that uses an ultrasonic sensor to monitor water levels and activate LED and buzzer alerts when a tank approaches its maximum capacity. The circuit is simulated using Tinkercad to demonstrate embedded systems design and water conservation.

Components

- Arduino Uno
- HC-SR04 ultrasonic sensor
- LEDs and resistors
- Buzzer

Working Principle

The ultrasonic sensor measures the distance to the water surface. Arduino processes the readings and activates alerts when predefined water-level thresholds are reached.

Tools Used

- Tinkercad Circuits
- Arduino C/C++

Objective

To reduce water wastage by providing timely warnings before a water tank overflows.


Future Improvements

- Automatic water pump shut-off
- Water-level history
- Mobile alerts
